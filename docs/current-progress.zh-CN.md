# 当前状态

## 实现状态

- 旧项目功能范围已经在当前实现中闭合，具体能力见[功能对等清单](feature-parity.zh-CN.md)。
- NoteIndex 是 Vault 笔记事实的唯一所有者；任务日期、区间和日历查询使用增量投影与结构共享。
- 月、周、年三种日历视图、五类周期笔记、任务、区间、八种界面语言、八个历法扩展、地区节假日和本地 ICS 均已接入当前数据主干。
- 设置页使用原生 Obsidian API；路径候选共享可释放目录并限制为排名最高的 100 项。
- 月/周区间溢出通过可访问的 `+N` 按钮打开当前周隐藏项，条目保持新标签打开语义。
- 插件先完成 UI 与宿主入口注册，布局就绪后后台启动 NoteIndex 和首次 ICS 刷新。NoteIndex 可从设备本地 IndexedDB 恢复元数据匹配的派生快照；完整路径对账与变化文件读取完成后快速进入 `ready`，随后立即在 8ms 时间片内逐篇读取校验。readiness 继续阻止未知路径被误建，缓存不进入 `data.json` 或 Vault 同步文件。
- 周期笔记删除与创建失败回滚使用 Obsidian 回收站接口；英文历法和中国大陆节假日不再残留中文名称。
- 日历内的打开/创建动作与 Obsidian 活动周期笔记使用同一语义选择；周/月/年视图保持不变，年摘要以月份内日号或周号表达精确选择，跨年周按多数日期所属月份导航。

## 当前自动验证

- `pnpm check` 通过，包括 Obsidian 专项 ESLint、源码格式、严格类型、完整 Vitest、生产构建和产物 smoke/size 契约。
- UTC 与 `America/New_York` 时区测试通过。
- 1,000 与 10,000 篇确定性基准通过；live create/modify 批次保持每终态路径一次读取，快速 32 路批次一次发布。
- 当前 Node 确定性基准中，1,000 篇冷初扫为 101.19ms、暖缓存元数据安全 ready 为 7.50ms；10,000 篇分别为 562.50ms 与 58.64ms。暖启动在 ready 前只读取上次错误的 5/48 篇，其余 995/9,952 篇从缓存恢复，并明确安排随后的完整后台逐字节校验；这些数字不是正式 Obsidian + OneDrive 的宿主测量。
- 0.2.1 production 候选在包含 18,286 篇 Markdown 的真实 Obsidian 1.12.7 桌面 Vault 中完成三轮全量 NoteIndex 初扫：每轮保持 18,286 次读取/解析、默认 16 路读取上限、一次发布和零错误，8ms 协作时间片产生 97–111 次 host macrotask 让步，总耗时为 848.8–1,000.5ms，三轮均未出现 `PerformanceObserver` 可见的 ≥50ms 长任务；同一环境优化前曾捕获 1,089ms 单个长任务。强制 GC 后 ready 与 stop 状态的稳定 renderer heap 差值约 16.3MB。
- 持久化缓存候选在当前包含 18,290 篇 Markdown 的同一正式 Obsidian 1.12.7 Vault 中完成一次缓存建立和三轮暖重载。当前 OneDrive 冷态首次建缓存耗时约 8.18s；三轮暖启动的元数据安全 ready 为 366.1–625.6ms，中位数 484.5ms，后台完整逐篇校验在启动后 2.06–2.46s 完成。每轮最终仍读取全部 18,290 篇，索引保持 18,290 条、错误 0；设备本地 IndexedDB 快照序列化约 9.10MB。该结果证明缩短了可用时间，不代表取消后续读取。
- 冷月装饰基准保持在十几毫秒量级，不再重复触发同语言的 lunar 全局消息更新。
- production `main.js` 低于 1,250,000 B 项目门禁；当前 `0.2.1` 显式八语言目录、完整历法组合、初扫时间片、设置重组、统一历法事件呈现、单一周期悬停预览、嵌入统计、持久化启动缓存与 Obsidian/Moment 周期格式构建为 1,178,739 B，相对已发布 0.1.2 基线增加 187,557 B，并保留 71,261 B 可审计余量。该值不是 Obsidian 平台限制；明细继续输出预算余量、相对基线增量和依赖包聚合。
- 年度节假日门禁通过；中国大陆下一年仅在一手来源确认官方安排尚未发布时以带来源警告的 `unavailable` 状态继续。
- 当前 0.2.0 production 产物已在自动生成的隔离桌面 Vault 中复验英文、简体中文与阿拉伯语设置、LTR/RTL 月/周视图、窄侧栏、ICS、日记状态、任务进度与班休标记共存；六个新增 `Intl` 历法均由实际 Electron 宿主确认可用。
- 同一 production 文件已按 SHA-256 部署到 Android 15 / API 35 模拟器的自动生成夹具副本；月/周/年、三语切换、阿拉伯语 RTL、横竖屏、周期选择器返回、前后台恢复、区间/任务和六个新增历法均通过。2 月 17 日的任务进度与休假、2 月 28 日的任务进度与补班在三语月/周视图中始终固定于物理左上/右上且无重叠；日志无插件异常、崩溃或 ANR。尚无物理 Android 设备证据。

## 当前发布状态

当前产物必须通过完整自动门禁和与本次变更相关的真实宿主回归。完整桌面兼容矩阵、真实移动设备矩阵和真实宿主大 Vault Profiler 按变更风险触发，而不是要求每个补丁版本无差别重跑：

1. 最低支持 Obsidian 1.12.7、执行时最新稳定桌面版或宿主集成表面发生变化时，重跑对应桌面矩阵；
2. 安全区、周期 Note Navbar、触摸、横竖屏或软键盘行为发生变化时，补真实移动设备矩阵；
3. NoteIndex、查询、缓存、依赖或产物预算发生性能相关变化时，补 1,000/10,000 篇真实宿主 Profiler、最长主线程任务和 heap 证据。

未触发或未取得的证据只限制对应兼容性、真机或性能结论，不阻止无关补丁发布，也不得被写成已经验证。

完整执行口径见[测试策略](testing-strategy.zh-CN.md#人工发布门禁)。
