# Chrono Notes

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Español](README.es-ES.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru-RU.md) · [Tiếng Việt](README.vi-VN.md) · [العربية](README.ar.md) · [فارسی](README.fa.md) · [עברית](README.he.md) · [አማርኛ](README.am.md) · [हिन्दी](README.hi.md)

Chrono Notes는 Obsidian에서 주기 노트, 작업, 지역 공휴일, 로컬 일정, 기간 노트를 함께 관리할 수 있는 달력 플러그인입니다.

이 문서는 일상적인 작업을 위한 **간단한 안내서**입니다. 자세한 설정과 제한은 [영문 전체 안내](../../README.md) 또는 [중국어 간체 전체 안내](README.zh-CN.md)를 참고하세요.

## 주요 기능

플러그인의 실제 UI를 브라우저 테스트 환경에서 렌더링한 현재 넓은 화면과 좁은 화면 예시입니다. Obsidian이나 Android에서 직접 촬영한 화면은 아닙니다.

![Chrono Notes · 840 px](../assets/chrono-notes-calendar-wide-en.png)

![Chrono Notes · 340 px](../assets/chrono-notes-calendar-narrow-en.png)

- 주·월·연·세기 달력에서 노트 상태, 작업, 통계, 미리 보기를 확인할 수 있습니다.
- 일간·주간·월간·분기·연간·10년·세기 노트를 내장 템플릿이나 Templater로 만들 수 있습니다.
- 노트 간 탐색, 작업 진행률, 히트맵, 선택한 날짜 범위의 기간 노트를 지원합니다.
- 중국 음력·간지, 페르시아력, 에티오피아력, 히브리력, 인도력, 이슬람력과 중국 본토·싱가포르 공휴일을 표시할 수 있습니다.
- 로컬 ICS 일정은 읽기 전용입니다. 날짜 속성의 YAML 값은 그대로 두고 표시 형식만 바꿀 수 있습니다.

## 요구 사항 및 호환성

데스크톱 또는 모바일 Obsidian 1.12.7 이상이 필요합니다. Vault 안에 저장된 ICS 파일은 지원 플랫폼에서 사용할 수 있으며, Vault 외부 경로는 데스크톱에서만 사용할 수 있습니다. 다른 역법은 실행 환경에서 제공하는 데이터에 따라 표시됩니다.

## 설치

### 커뮤니티 플러그인

Obsidian의 **설정 → 커뮤니티 플러그인 → 탐색**에서 **Chrono Notes**를 검색하고 **설치**, **활성화**를 차례로 선택합니다.

### 수동 설치

[최신 릴리스](https://github.com/ZHYX91/obsidian-chrono-notes/releases/latest)에서 `chrono-notes-<version>.zip`을 받아 `Vault/.obsidian/plugins/`에 압축을 풉니다. `chrono-notes/` 폴더에 `main.js`, `manifest.json`, `styles.css`가 있어야 합니다. Obsidian을 다시 로드한 뒤 활성화합니다.

### 업데이트

업데이트할 때는 `main.js`, `manifest.json`, `styles.css`만 교체하세요. 기존 `data.json`은 백업 후 보관하세요. 설정을 초기화하려는 경우가 아니라면 삭제하지 마세요.

## 사용 방법

기본 달력, 월 선택기, 날짜 대화상자는 항상 그레고리력을 사용합니다. 언어를 바꾸면 월 이름과 숫자 표기가 바뀌지만 달력 체계는 바뀌지 않습니다. 다른 달력 정보가 필요하면 달력 확장을 따로 선택하세요.

**ICS를 추가하기 전에:** Chrono Notes는 로컬 파일만 읽고 원격 달력 구독은 가져오지 않습니다. `RRULE`이나 `RDATE`가 있는 반복 일정은 펼치지 않고 건너뛴 수를 알려 줍니다. 반복 규칙이 많은 일정은 일부가 표시되지 않을 수 있으며 Vault 밖의 파일 경로는 데스크톱에서만 지원됩니다.

설정에서 사용할 주기 노트 종류와 경로, 템플릿을 지정하고 리본 아이콘이나 명령 팔레트로 달력을 엽니다. **날짜를 한 번 클릭하면 선택만 되며 노트가 만들어지지 않습니다.** 두 번 클릭하거나 Enter를 누르면 노트를 열거나 만듭니다. 오른쪽 클릭으로 날짜 메뉴를 엽니다. ICS 일정이 있는 날짜라면 이 메뉴에서 전체 일정 목록을 볼 수 있습니다. Ctrl/Cmd+클릭 또는 가운데 클릭으로 새 탭에서 열 수 있습니다. 필요한 경우 달력 확장 기능과 ICS 원본을 설정하세요.

터치 화면에서는 날짜를 길게 눌러 메뉴를 연 뒤 일간 노트를 열거나 만드는 작업을 선택합니다. 메뉴가 나타나지 않으면 손가락을 뗄 때 일간 노트를 열거나 만듭니다. 주, 월 등 기간을 나타내는 칸을 길게 누르면 해당 노트가 바로 열립니다.

월간 보기에서 날짜를 선택하면 달력 아래에서 노트 상태, 역법 정보, 공휴일 및 원본이 표시된 전체 ICS 일정 목록을 확인할 수 있습니다. 생성 확인이 켜져 있으면 대화상자에 대상 경로와 만들거나 유지할 상위 주기 노트가 표시됩니다.

### 달력에 작업 표시하기

노트에 체크박스가 있는 작업을 작성하고 날짜 표시를 추가하세요.

```markdown
- [ ] 주간 보고서 제출 📅 2026-10-20
- [ ] 자료 준비 🛫 2026-10-18 ⏳ 2026-10-19 📅 2026-10-20
- [ ] 보고서 검토 ⏳ 2026-10-20 📅 2026-10-20
```

`🛫`는 시작일, `⏳`는 예정일, `📅`는 마감일입니다. 날짜는 `YYYY-MM-DD` 형식으로 입력합니다. 주간 보기에는 이 날짜 중 하나가 표시 중인 주에 속하는 작업이 나옵니다. 날짜가 다르면 각각의 날짜에 표시되며, 같은 날짜를 가리키는 표시가 여러 개이면 한 항목으로 합쳐집니다. 따라서 마지막 예시 작업은 10월 20일에 한 번만 표시됩니다. 날짜가 없는 작업도 해당 노트의 작업 진행률에는 포함됩니다.

주간 보기의 마감일 드롭다운에서 같은 주의 다른 날짜를 선택해 마감일을 바꿀 수 있습니다. 데스크톱에서는 마감일이 있는 작업을 원하는 날짜로 끌어다 놓을 수도 있습니다. 이 작업은 원본 노트에 이미 적혀 있는 마감일을 수정합니다.

주간 보기의 체크박스는 원본 노트의 작업 완료 상태를 바꿉니다. 업데이트 중에는 해당 작업의 체크박스, 마감일 선택, 드래그가 비활성화되며 실패나 저장 경고가 작업 옆에 표시됩니다. 결과가 불확실하면 원본 노트를 확인한 후 다시 시도하세요. 100개가 넘으면 ‘이전 작업’과 ‘다음 작업’으로 페이지를 이동하며 전체 항목 수는 그대로 표시됩니다.

### 10년 노트와 세기 노트

세기 보기에서는 10년 단위 칸 옆에 연도를 5개씩 두 줄로 표시합니다. 화면이 좁으면 10년 칸이 연도 위쪽으로 이동합니다. 패널이 매우 좁거나 글자 크기가 크면 연도를 두 열로 표시합니다. 해당 세기 밖의 연도는 빈칸으로 남습니다. 이 보기를 열면 선택한 연도가 속한 10년을 보여 줍니다. '이번 세기'를 누르면 현재 10년으로 돌아가며 연도 목록을 스크롤해도 상단 탐색 버튼은 보입니다.

설정에서 10년 노트와 세기 노트를 사용하도록 설정한 다음 사이드바에서 '세기'를 선택하세요. 10년과 세기에는 각각 별도 칸이 있습니다. 한 번 클릭하면 선택만 되고, 두 번 클릭하거나 Enter를 누르면 노트를 열거나 만듭니다. Ctrl/Cmd+클릭이나 가운데 클릭은 새 탭에서 열고, 터치 화면에서는 길게 누를 수 있습니다. 노트 상태 표시, 작업 진행률 및 미리 보기는 연간 보기와 같습니다. 기본 경로는 10년 노트가 `[diary]/DEC[s]`(2020s), 세기 노트가 `[diary]/[C]CEN`(C21)입니다.

10년은 예를 들어 2020~2029년이고, 21세기는 2001~2100년입니다. `DEC`와 `CEN`은 인터페이스 언어와 관계없이 고정된 숫자를 출력합니다. 세기 폴더와 10년 폴더를 동시에 중첩하기보다 둘 중 하나를 고르는 편이 좋습니다. 2000년대는 C20/C21에 걸치지만 10년 노트는 시작 연도 2000년에 따라 C20에 속합니다. 기존 노트는 자동으로 이동하지 않습니다.

템플릿에서 `{{date:DEC[s]}}`, `{{date:[C]CEN}}`, `{{start:YYYY}}–{{end:YYYY}}`를 사용할 수 있습니다. 모든 주기 노트 템플릿은 시작일, 종료일, 양 끝 날짜를 포함한 일수 `{{days}}`를 제공합니다. 각 노트 설정에 자리표시자와 예시, Templater 표현식이 있으며 공통 규칙은 '일반 → 템플릿 설정'에서 확인할 수 있습니다.

### 기간 노트

먼저 **설정 → Chrono Notes → 기간 노트**에서 저장할 폴더를 선택하세요. 데스크톱에서는 월간 달력에서 시작 날짜부터 다른 종료 날짜까지 드래그해 기간 노트를 만들 수 있습니다. 날짜 메뉴나 명령 팔레트에서 기간 노트 만들기를 선택한 뒤 날짜를 입력해도 됩니다. 새 노트를 만들려면 최소 두 날짜에 걸친 기간이 필요합니다. 시작일과 종료일이 뒤바뀌어 있으면 자동으로 순서를 바꿉니다.

기존 노트를 기간으로 표시하려면 Markdown 파일 맨 위에 다음 속성을 추가하세요.

```yaml
---
chrono-notes: interval
start: 2026-10-18
end: 2026-10-20
---
```

날짜는 완전한 `YYYY-MM-DD` 형식으로 입력하고, 시작일이 종료일보다 늦지 않게 하세요. 표시되는 기간에는 시작일과 종료일이 모두 포함됩니다. 기존 노트는 최소한 시와 분을 포함한 완전한 ISO 날짜·시간이나 하루 안의 기간도 지원합니다.

기간 노트에는 유효한 `start`와 `end` 속성이 있어야 합니다. Chrono Notes가 새로 만드는 기간 노트에는 `chrono-notes: interval`도 기록하므로 Vault 어디에 있든 인식할 수 있습니다.

`chrono-notes` 속성이 없는 노트는 설정한 '표시가 없는 기간 노트 검색 범위' 안에 있을 때만 인식됩니다. 속성 값이 `interval`이 아닌 경우 기간 노트에서 제외합니다. 기존 노트는 자동으로 바꾸지 않습니다.

## 설정

일반 설정에서 사용 안내와 문제 보고를 열 수 있습니다. 달력이나 공휴일 확장을 바꿔도 현재 설정 탭이 보이는 상태로 유지되고 키보드 포커스는 방금 사용한 컨트롤에 남습니다.

언어, 주 시작 요일, 날짜 표시 형식, 노트 경로와 템플릿을 설정할 수 있습니다. 파일 이름에 쓰는 언어를 변경해도 기존 파일은 이름이 바뀌지 않으므로 경로 미리 보기를 확인하세요. 화면 표시, 작업, 통계, 기간 노트 및 달력 확장 기능에는 별도 설정이 있습니다.

## 제한 사항

- ICS 파일은 로컬 읽기 전용이며 원격 구독을 직접 가져오지 않습니다. 기본적으로 갱신할 때 최대 32개 원본을 읽고, 상한을 넘은 원본은 생략되었다고 표시합니다. `RRULE` 또는 `RDATE`가 있는 반복 일정은 건너뛰고 그 수를 집계합니다.
- 파일에 포함된 시간대 정의는 명시된 시각 변경 날짜와 일부 연간 규칙(`FREQ=YEARLY`)을 지원합니다. 정의가 잘못되었거나 지원되지 않거나 너무 복잡하면 해당 시간대를 사용하는 일정을 건너뛰고 알립니다. 지원 규칙과 상한은 영어로 된 [날짜 및 시간대 문서](../calendar-boundaries.en.md)에서 확인할 수 있습니다.
- 아직 발표되지 않은 공휴일은 예측하지 않습니다. 달력 확장 기능은 표시만 바꾸며 노트 이름, 날짜 탐색, 작업 날짜는 계속 그레고리력을 사용합니다. 실행 환경에서 지원하지 않는 확장 기능은 숨겨집니다.

## 개인정보 보호 및 보안

달력과 색인을 만들기 위해 필요한 Markdown 노트와 선택한 로컬 ICS 파일을 읽습니다. 노트나 일정 데이터를 업로드하지 않으며 계정도 필요 없습니다. 파생 색인은 기기의 IndexedDB에 저장하고 언제든 다시 만들 수 있습니다. 클립보드는 읽지 않으며 '날짜 복사'를 선택한 경우에만 날짜를 기록합니다.
