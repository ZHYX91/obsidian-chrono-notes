# Chrono Notes

[English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Español](README.es-ES.md) · [Português](README.pt-BR.md) · [Русский](README.ru-RU.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Tiếng Việt](README.vi-VN.md) · [العربية](README.ar.md) · [فارسی](README.fa.md) · [עברית](README.he.md) · [አማርኛ](README.am.md) · [हिन्दी](README.hi.md)

Chrono Notes は Obsidian に、定期ノート、タスク、祝日、ローカル予定、期間ノートをまとめて扱うカレンダーを追加するプラグインです。

## 主な機能

デスクトップ版と Android 版のカレンダー画面：

![Chrono Notes デスクトップ版のカレンダー](../assets/chrono-notes-desktop-en.png)

![Chrono Notes Android 版のカレンダー](../assets/chrono-notes-android-en.png)

- 週・月・年・世紀の表示で、ノートの有無、タスク、統計、プレビューを確認できます。
- 日・週・月・四半期・年・十年・世紀単位のノートを、内蔵テンプレートまたは Templater で作成できます。
- ノート間ナビゲーション、タスク進捗、ヒートマップ、日付範囲を指定した期間ノートに対応しています。
- 中国旧暦・干支、ペルシャ暦、エチオピア暦、ヘブライ暦、インド暦、イスラム暦、中国本土・シンガポールの祝日表示に対応しています。
- ローカル ICS ファイルは読み取り専用です。Obsidian の日付プロパティは YAML を変更せず表示形式だけを調整できます。

## 動作環境と互換性

デスクトップ版・モバイル版の Obsidian 1.12.7 以降が必要です。Vault 内の ICS ファイルは対応端末で利用できますが、Vault 外のパスを直接指定できるのはデスクトップ版のみです。追加の暦は Obsidian の実行環境に依存します。

## インストール

### コミュニティプラグイン

Obsidian の **設定 → コミュニティプラグイン → 閲覧** から **Chrono Notes** を検索し、**インストール**して**有効化**します。

### 手動

[最新リリース](https://github.com/ZHYX91/obsidian-chrono-notes/releases/latest)から `chrono-notes-<version>.zip` を入手し、`Vault/.obsidian/plugins/` に展開します。`chrono-notes/` フォルダーに `main.js`、`manifest.json`、`styles.css` があることを確認し、Obsidian を再読み込みして有効化します。

### 更新

既存の `data.json` はバックアップして保持してください。設定を初期化したい場合を除き、削除しないでください。

## 使い方

設定で使用するノートの種類、保存先、テンプレートを選び、リボンまたはコマンドパレットからカレンダーを開きます。**日付を1回クリックしても選択されるだけで、ノートは作成されません。** ダブルクリックか Enter でノートを開く・作成する操作が実行されます。右クリックで日付メニューを開けます。ICS の予定がある日は、このメニューから予定の全一覧を確認できます。Ctrl/Cmd＋クリックか中クリックで新しいタブに開けます。必要に応じて追加の暦や ICS の参照元を設定してください。

タッチ画面では、日付を長押ししてメニューを開き、デイリーノートを開く・作成する操作を選びます。メニューが表示されない場合は、指を離したときにデイリーノートを開くか作成します。週や月などの期間のマスを長押しした場合は、対応するノートを直接開きます。

### タスクをカレンダーに表示する

ノートにチェックボックス付きのタスクを書き、日付マーカーを追加します。

```markdown
- [ ] 週報を提出する 📅 2026-10-20
- [ ] 資料を準備する 🛫 2026-10-18 ⏳ 2026-10-19 📅 2026-10-20
- [ ] 報告書を確認する ⏳ 2026-10-20 📅 2026-10-20
```

`🛫` は開始日、`⏳` は予定日、`📅` は期限です。日付は `YYYY-MM-DD` 形式で記入します。週表示には、いずれかの日付が表示中の週に含まれるタスクが並びます。日付が異なればそれぞれの日に表示され、同じ日のマーカーが複数あっても表示は1件にまとまります。上の最後のタスクは、10月20日に1回だけ表示されます。日付のないタスクも、元のノートのタスク進捗には含まれます。

週表示の期限ドロップダウンで、同じ週の別の日に期限を変更できます。デスクトップでは、期限付きのタスクを目的の日にドラッグすることもできます。どちらの操作も、元のノートに書かれている既存の期限を書き換えます。

### 十年ノートと世紀ノート

世紀表示では、十年のマスの横に5年ずつ2行で年を表示します。幅が狭い場合は十年のマスが上に移ります。ペインが非常に狭い場合や文字サイズが大きい場合は、年を2列で表示します。世紀の範囲外の年は空欄になります。表示を開くと、選択中の年が属する十年が見える位置に移動します。「今世紀」は現在の十年に戻り、年をスクロールしてもナビゲーションは上部に残ります。

設定で十年ノートと世紀ノートを有効にして、サイドバーで「世紀」を選びます。十年と世紀はそれぞれ独立したマスがあります。1回クリックすると選択、ダブルクリックまたは Enter で開く・作成を行います。Ctrl/Cmd＋クリックや中クリックでは新しいタブ、タッチでは長押しが使えます。ノートの状態表示、タスク進捗、プレビューは年表示と共通です。既定のパスは、十年ノートが `[diary]/DEC[s]`（2020s）、世紀ノートが `[diary]/[C]CEN`（C21）です。

十年は例えば2020〜2029年、21世紀は2001〜2100年です。`DEC` と `CEN` は表示言語に関係なく決まった数字を出力します。十年と世紀の両方でフォルダーを入れ子にせず、どちらか一方で整理することを勧めます。2000年代は C20 と C21 にまたがりますが、開始年の2000年に従い十年ノートは C20 に属します。既存ノートが自動で移動することはありません。

テンプレートの書式も共通です：`{{date:DEC[s]}}`、`{{date:[C]CEN}}`、`{{start:YYYY}}–{{end:YYYY}}`。すべての定期ノートのテンプレートで、開始日・終了日と両端を含む日数 `{{days}}` を使えます。各設定ページにはプレースホルダーと使用例、Templater での書き方があり、共通仕様は「一般 → テンプレート設定」にあります。

### 期間ノート

まず **設定 → Chrono Notes → 期間ノート** で保存先フォルダーを選びます。デスクトップでは、月表示のカレンダーで開始日から別の終了日までドラッグすると期間ノートを作成できます。日付メニューやコマンドパレットから期間ノートの作成を選び、日付を入力する方法もあります。新規作成時は、少なくとも2つの日付にまたがる期間を指定してください。開始日と終了日が逆の場合は、自動で入れ替えます。

既存のノートを期間として表示するには、Markdown ファイルの先頭に次のプロパティを追加します。

```yaml
---
chrono-notes: interval
start: 2026-10-18
end: 2026-10-20
---
```

日付は完全な `YYYY-MM-DD` 形式にし、開始日が終了日より後にならないようにしてください。表示される期間には両端の日付を含みます。既存のノートでは、少なくとも時と分を含む完全な ISO 日時や、同じ日内の期間も使えます。

期間ノートには、有効な `start` と `end` プロパティが必要です。Chrono Notes が新規作成する期間ノートには `chrono-notes: interval` も書き込まれるので、Vault 内のどこに置いても認識されます。

`chrono-notes` プロパティがないノートは、設定した「印のない期間ノートの検索範囲」内にある場合だけ認識されます。このプロパティの値が `interval` 以外なら対象外です。既存ノートは自動で書き換えられません。

## 設定

言語、週の開始曜日、日付の表示形式、ノートのパスとテンプレートを設定できます。ファイル名に使う言語を変更しても既存ファイルは自動的に改名されないため、パスのプレビューを確認してください。表示、タスク、統計、期間ノート、拡張機能にも設定があります。

## 制限事項

- ICS はローカルの読み取り専用ファイルで、リモート購読の直接取得には対応していません。1回の更新で読む参照元は既定で最大32件で、上限を超えた参照元は省略したことを表示します。`RRULE` / `RDATE` を持つ繰り返し予定は読み飛ばし、その件数を報告します。
- ファイル内のタイムゾーン定義では、明示された時刻の切り替え日と、一部の年単位のルール（`FREQ=YEARLY`）に対応します。定義が無効、非対応、または複雑すぎる場合は、そのタイムゾーンを使う予定を読み飛ばして報告します。対応するルールと上限の詳細は、英語の[日付とタイムゾーンの仕様](../calendar-boundaries.en.md)にあります。
- 未発表の祝日は予測しません。追加の暦は表示だけを変更し、ノート名、日付の移動、タスクの日付には引き続きグレゴリオ暦を使います。実行環境が対応していない暦は表示しません。

## プライバシーとセキュリティ

カレンダー表示と索引のため、必要な Markdown ノートと指定されたローカル ICS を読み込みます。ノートや予定を外部に送信することはなく、アカウントも不要です。派生した索引は端末内の IndexedDB に保存され、再構築できます。クリップボードは読み取らず、「日付をコピー」を選んだ場合に限り日付を書き込みます。
