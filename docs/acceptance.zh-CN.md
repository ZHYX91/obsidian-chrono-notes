# 候选验收记录

## 3. 桌面宿主结果

在一次性隔离 Vault 和 Obsidian 1.13.7 桌面宿主中通过以下验收：

- 插件启用，设置页显示 Chrono Notes 0.4.4；八种显式语言与“跟随 Obsidian”均可发现，选择跟随宿主后使用宿主中文且持久化为 `auto`。
- 首次引导在实际显示后才把 `firstUseGuideSeen` 写为 `true`；重启后不重复显示。
- 同一 Markdown 投影只索引一个真实任务，预览只显示可见正文、真实链接、真实标签和一个真实嵌入；代码围栏、行内代码和 HTML 注释中的伪任务、日期、链接、标签与嵌入均被隔离。日历报告 18 个词、0/1 个完成任务和 1 个图片；源笔记 SHA-256 在交互前后保持 `f73391c4761337873cd66b7253137c32635ac3948ed6eced3771ddfde4b4c90d`。
- 配置提升到未来 schema 19 并加入未知字段后，界面中的设置尝试未写入磁盘；配置 SHA-256 保持 `ba3caac9d68249113347596d6922362d95906b11ab549c22549485ca36de6b92`，`locale: auto` 与未知字段均保留。
- 日历显示本地 ICS 的全天、定时与跨日事件；周笔记可打开，并关联三个重叠区间笔记；区间起止属性正确。宿主重启后当前笔记、日历索引、区间关联和语言设置均恢复。

## 4. 确定性边界证据

本机没有可复用的 Templater 插件候选，因此没有声称完成真实 Templater 宿主集成。完整门禁中的 adapter 与命令测试证明：Templater 不可用时明确失败；同一实例的运行配置与解析临界区串行；周期和区间笔记的延后渲染失败会回滚新目标并允许重试。

ICS 普通来源已在桌面宿主中验证。资源上限由完整门禁的确定性测试固定：去重后最多 32 个来源，全局最多 4 个并发读取，单来源最多 5 MiB UTF-8 字节和 10,000 个 `VEVENT`，超限输入在组件构造前拒绝；跨 revision 的迟到结果不得覆盖当前状态。

## 5. 移动覆盖

Android 15 / API 35 模拟器能够启动，设备端三个候选运行文件的哈希与第 2 节一致。全新数据镜像中的现有 Obsidian 安装要求系统级文件管理权限，而验收不得操作或绕过系统隐私与安全设置。同一 AVD 不存在可证明干净、已获权限且可恢复的 `clean_zh_gboard` 快照，因此移动端核心宿主行为标记为基础设施未覆盖，不推断为产品通过或失败。隔离 Vault 和模拟器数据已清理。
