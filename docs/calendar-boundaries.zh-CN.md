# Chrono Notes — 日历身份与时间边界

## 1. 周期笔记路径

路径格式必须包含所选笔记周期所需的身份字段，不论是否使用 `DEC` 或 `CEN`。日记至少需要年、月、日，或完整的 ISO 周年、周号与星期；周记需要完整日期或 ISO 周年与周号；月记需要年与月；季记需要年与季度或月份；年记需要年份。年代与世纪笔记分别使用 `DEC`、`CEN` 或年份。

例如，`[Daily]/YYYY-MM` 不能用作日记路径，`[Monthly]/YYYY` 不能用作月记路径。无效规则在查询与打开/创建命令中均不生效，不会打开可能属于其他周期的同名文件。设置预览还必须确认解析结果属于原来的周期，而不只是确认路径能够被解析。两位年份格式保留既有解析规则；预览不能把解析到另一个世纪的结果显示为有效。长期使用优先选择四位年份。

文件名/路径语言属于稳定身份设置，与界面语言以及模板/显示语言分离。缺少 `pathLocale` 时，规范文件名语言固定为英文。升级到 schema 19 时，仅对真正包含本地化月份或星期 token（`MMM`、`MMMM`、`ddd`、`dddd`）的既有路径固化升级前实际生效的语言；纯数字、`DEC` 与 `CEN` 路径不写入冗余语言状态。因此，之后切换界面语言不会悄悄把既有本地化周期规则指向另一批文件。修改路径语言设置只影响之后的路径解析；Chrono Notes 不会自动重命名或迁移任何既有笔记文件。

较大周期笔记的级联创建仍按目标逐项尽力执行。某个较大周期创建失败时，不删除已经打开的主笔记，也不删除此前成功创建的较大周期笔记，并继续尝试后续已启用周期。所有尝试结束后，聚合后的级联失败会提升到插件命令边界，让用户收到一次可见错误，而不是留下无提示的部分成功结果。

配置校验不迁移或重命名既有笔记。发现无效规则时，用户需要修正格式并自行确认既有文件的日期归属。

## 2. ICS 时间语义

按照 RFC 5545 第 3.3.6 节，`DURATION` 的周、日按事件源时区的日历计算，然后再增加时、分、秒。`P1D` 与 `PT24H` 在夏令时切换处可能不同。仅在计算完成后将起止时间转换为显示时区。UTC 来源保持 UTC 算术；浮动时间以显示时区作为其解释时区；全天日期保持无时区日期语义。

按照 RFC 5545 第 3.6.1 节，没有 `DTEND` 和 `DURATION` 的日期时间事件是时间点，不补一分钟。索引将它恰好放在显示时区的开始日期，即使开始时间正好是午夜。没有结束字段的全天事件仍持续一个日历日，全天结束日期仍是排他的。

显式相等或倒置的 `DTEND`、零或负的 `DURATION`、同时存在两种结束字段以及日期类型不匹配仍按现有无效事件规则隔离。这里不增加重复事件展开能力，也不改变既有 ICS 输入与事件跨度上限。

## 3. 任务写入

任务改期从最新 Markdown 投影的语义文本定位到期日期，与任务解析使用同一遮罩语义。写回只替换对应日期字符，不替换前方行内代码或 HTML 注释中的相似标记，保留标记间距、原始换行和无关文本。

已打开的单一 Markdown 编辑器使用最小差异范围提交事务，不再替换全文；未打开的文件仍通过 `Vault.process` 原子校验和写回。多个编辑器、已变更的编辑器身份或改写过程中变化的缓冲区仍拒绝写入。这里不改变任务索引的事件驱动更新方式，也不绕过最新任务身份校验。

## 4. 世纪视图键盘操作

世纪视图只保留一个 Tab 停靠点，依次优先选择仍可见的键盘焦点、选中周期、当年或第一个周期。Tab 不被拦截，可以离开日历。

左右方向键按周期显示顺序移动，并遵循 RTL 方向；年份的上下方向键移动五个年份，世纪/年代标题的上下方向键在标题之间移动。Home/End 到达首尾周期。焦点移动不创建或打开笔记，不改变语义选中状态；Enter 保留原来的选中并打开行为，鼠标和长按行为保持不变。笔记刷新保留仍可见的焦点停靠点，切换世纪后提供有效回退。

## 5. 回归验证

路径测试覆盖缺少周期字段、字面量伪装为格式字段、合法规则优先级、闰日、跨月跨年、周日开始的跨年周、切换界面语言时本地化文件名身份保持稳定、仅迁移语言敏感路径，以及无效规则不得调用文件或工作区端口。预览测试区分路径可解析与周期身份一致。级联测试确认某个较大周期失败时该目标保持不存在，而主笔记与后续成功周期继续保留，并在主笔记打开后向上报告失败。

ICS 测试覆盖春秋两次夏令时切换、源时区不同于显示时区、`P1D`、`PT24H`、`P1W`、混合时长、浮动时间、UTC 来源、午夜与午夜前的时间点，以及全天排他结束。既有无效结束字段与取消/重复事件测试继续保留。

任务测试覆盖隐藏日期标记、UTF-16 坐标、各种换行、最小编辑事务、无变化与拒绝写入。世纪视图测试覆盖单一停靠点、方向键、Home/End、Enter、RTL、刷新保持和跨世纪回退。

运行 `npm run check` 和 `npm run test:timezones` 验证源码与确定性日期行为。它们不替代真实 Obsidian 的桌面、移动端或主题验收。
